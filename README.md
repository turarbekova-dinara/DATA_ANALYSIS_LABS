# Data Storage and Data Analysis - Laboratory Works

This repository contains a comprehensive set of laboratory assignments and practical projects focused on big data processing, data analysis, cloud integrations, and database management, completed as part of the academic curriculum at **Kazakh-British Technical University (KBTU)**.

## Repository Overview
The course covered advanced techniques for querying both structured and unstructured data, performing comprehensive data analysis using Python, and working within cloud and distributed data storage environments. The practical workflows are executed inside interactive environments.

## Technologies, Frameworks & Libraries Used
* **Languages & Environments:** Python , Jupyter Notebook (`.ipynb`)
* **Data Analysis & Visualization:** NumPy, Pandas, Matplotlib, Seaborn *(for manipulating massive datasets, plotting graphs, and statistical visualization)*
* **Databases & Storage (SQL & NoSQL):** 
  * Relational Databases: PostgreSQL, SQL queries
  * Non-Relational Databases: MongoDB 
* **Cloud & Distributed Computing:** Cloud infrastructure concepts, cloud data storage models, and big data platform architectures (Google Cloud/Cloud Storage systems).

## 📂 Project Focus & Lab Work Structure
* **Exploratory Data Analysis (EDA):** Cleaning large-scale datasets, handling missing values, calculating statistical summaries, and extracting insights using **NumPy** and **Pandas**.
* **Data Visualization:** Building analytical plots, correlation heatmaps, trends, and distribution graphs via **Matplotlib** and **Seaborn**.
* **Database Management:** Writing optimized SQL queries for **PostgreSQL** and managing unstructured document-based collections inside **MongoDB**.
* **Cloud Infrastructure:** Practical labs simulating big data pipelines and storage mechanisms utilizing modern cloud engineering architectures.
